# 자모냥

한글 자음·모음으로 만드는 슬라이딩 블록 퍼즐 — 웹 프로토타입. 기획은 [docs/기획서.md](docs/기획서.md).

모음 모양 블록(ㅏ ㅣ ㅡ ㅗ …)을 밀어서, 같은 오음(五音) 계열 색의 자음을 태워 글자를 완성합니다.

## 실행

빌드 없이 정적 파일만으로 돌아갑니다.

```bash
python3 -m http.server 8000   # 그리고 http://localhost:8000
```

(`index.html`을 파일로 바로 열어도 동작합니다.)

## 구현된 것

- 규칙: 축 방향 슬라이딩, 맞닿으면 흡수(손을 뗀 위치 기준), 블록 숫자 0이면 사라짐, 전부 비우면 클리어
- 오음 색 규칙 (아음·설음·순음·치음·후음)
- 위치 규칙: 세로 모음은 왼쪽, 가로 모음은 위쪽에서만 흡수 (월드 2부터)
- 자음 주머니(가장자리 공급), 쌍자음(2칸), 옛한글 돌(인접 블록 3번 완성 시 깨짐), 얼음 자음(두 번 닿아야 흡수), 회전 모음(탭해서 ㅏ↔ㅓ)
- 단어 보너스(소사전), 숨은 단어, 별 3개, 타이머, 아이템 4종(붓·지우개·도장·한지), 진행 저장
- 레벨 10개 (서당 5 · 장터 3 · 궁궐 2)

## 레벨 검증 (BFS 솔버)

```bash
node tools/solve.js          # 모든 레벨 해답 존재 + 최소 수(par) 일치 + 숨은 단어 달성 가능 확인
node tools/solve.js 5 --path # 특정 레벨 풀이 경로 출력
```

## 구조

| 파일 | 역할 |
|---|---|
| `js/hangul.js` | 오음 색, 모음 블록 모양, 글자 조합(유니코드 공식), 단어 사전 |
| `js/engine.js` | 화면과 무관한 규칙 엔진 (브라우저·Node 공용) |
| `js/levels.js` | 레벨 데이터 (9×6 문자 맵 + 블록/주머니) |
| `js/game.js` | Canvas 렌더링, 드래그 입력, 애니메이션, 저장 |
| `tools/solve.js` | 레벨 솔버 |
