# 백성을 구해라

6살 아이를 위한 한글 모양 퍼즐 (웹). 플레이어는 **문종** — 세자 시절 측우기를 만든 임금이 되어, 비 맞는 백성에게 **자음·모음 모양 지붕**을 씌워 줍니다.

## 규칙

- 보드 위에 비 맞는 백성이 서 있고, 그 둘레에 글자 모양 **자리**(같은 색 점선)가 있어요.
- 자음·모음 모양 **블록(지붕)**을 손가락으로 끌어 같은 모양 자리에 **딱 맞게 덮으면** 그 자리 백성을 구해요.
- 백성을 구한 지붕은 백성과 함께 **떠나서 길이 열려요.** 그래서 길을 막은 지붕부터 보내는 순서가 퍼즐이 됩니다.
- **초가집**이 붙은 자리는 한 무리를 구하면 다음 무리가 나오고, 자리 글자가 바뀌어요(지붕 위 빨간 숫자 = 남은 무리).
- 판은 네모가 아닐 수 있어요. 빈 곳과 바위·물은 지나갈 수 없어요.
- 모든 백성을 구하면 "잘했어요!" 불꽃과 함께 클리어. 실패·타이머 없음.

## 아이를 위한 장치

- 블록은 끄는 대로 한 칸씩 따라오고 바위·물·다른 블록은 피해 가요. 자리 한 칸 근처에 놓으면 자석처럼 쏙 들어갑니다.
- ↩ 되돌리기, 💡 힌트(움직일 블록과 갈 곳을 반짝임 + 말로 안내), 🗣️ 다시 듣기
- 길이 막히면 솔버가 알아채서 "되돌리기를 눌러 주시옵소서"라고 알려 줘요.
- 별 3개: 모두 구하기 / par+2번 이내 / 힌트 없이

## 음성 (브라우저 한국어 TTS)

- 블록을 잡는 순간 한 번 이름: "기역", "아"
- 자리나 지붕을 누르면: "기역 자리예요"
- 구했을 때: "기역! 백성 세 명을 구했사옵니다!"
- 단계 시작 신하의 말, 완성 시 "성은이 망극하옵니다!"

## 실행

```bash
python3 -m http.server 8000   # 그리고 http://localhost:8000
```

## 자모 모양 점검

주소 끝에 `#atlas`를 붙여 열면(예: `http://localhost:8000/#atlas`) 40개 블록을 한 판에서 볼 수 있어요.

## 단계 검증

```bash
node tools/solve.js          # 모든 단계 해답 + 최소 수(par) + 함정(바로 넣으면 막히는 첫 수) 수
node tools/solve.js 10 --path
```

## 구조

| 파일 | 역할 |
|---|---|
| `js/hangul.js` | 자모 40개(자음 19 · 모음 21) 블록 모양(격자 그림), 이름(읽기용), 단청 색 |
| `js/engine.js` | 규칙 엔진 + BFS 솔버 (브라우저 힌트·Node 검증 공용) |
| `js/levels.js` | 26단계 (첫 비 · 장마 · 큰비 · 모음 마을 · 자음 마을 · 쌍둥이 마을 · 겹모음 마을) |
| `js/game.js` | Canvas 렌더링, 드래그, 음성, 힌트/되돌리기, 저장 |
| `tools/solve.js` | 단계 검증 + 자모 40개가 모두 나오는지 확인 |
| `tools/gen-levels.js` | 글자 목록으로 단계를 무작위 배치하고 솔버로 골라 주는 생성기 (11~26단계) |
