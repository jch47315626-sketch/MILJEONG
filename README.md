# 자모냥

한글 자음·모음으로 만드는 슬라이딩 블록 퍼즐 — 웹 프로토타입. 기획은 [docs/기획서.md](docs/기획서.md).

모음 모양 블록(ㅏ ㅣ ㅡ ㅗ …)을 밀어서, 같은 오음(五音) 계열 색의 자음을 태워 글자를 완성합니다.

## 실행

빌드 없이 정적 파일만으로 돌아갑니다.

```bash
python3 -m http.server 8000   # 그리고 http://localhost:8000
```

(`index.html`을 파일로 바로 열어도 동작합니다.)

## 6살 눈높이 설계

한글 교육용이라 어린아이도 혼자 할 수 있게 맞췄습니다.

- **그림 단어 12개**: 👃코 🦷이 🦁사자 🌊바다 🌳나무 🦆오리 👶아기 🥛우유 👒모자 🚂기차 🦋나비 🍌바나나 — 단계마다 하나씩 만든다
- **1~2수면 클리어**: 5×6 큰 칸 보드, 블록 1~2개
- **실패 없음**: 타이머 없음, 막히면 ↩ 되돌리기, 💡 힌트(솔버가 다음 수를 화살표로 보여 주고 말로도 알려 줌)
- **손이 서툴러도 OK**: 반 칸만 끌어도 그 방향 끝까지 미끄러진다
- **음성(브라우저 한국어 TTS)**
  - 모음 블록을 잡는 순간 한 번: "아", "오" …
  - 자음이 블록으로 옮겨 갈 때: "기역, 가"
  - 자음을 누르면: "기역"
  - 단계 시작 시 안내, 완성 시 단어 + 칭찬, 단어 칸·🗣️ 버튼으로 다시 듣기
- **별 3개**: 완성 / par+2수 이내 / 단어를 순서대로 완성

> 위치 규칙·얼음·옛한글 돌·회전 모음·아이템은 엔진에 남아 있지만(기획서 월드 2~4용) 현재 레벨에서는 쓰지 않습니다.

## 레벨 검증 (BFS 솔버)

```bash
node tools/solve.js          # 모든 레벨 해답 존재 + 최소 수(par) 일치 + 단어를 순서대로 만들 수 있는지 확인
node tools/solve.js 5 --path # 특정 레벨 풀이 경로 출력
```

## 구조

| 파일 | 역할 |
|---|---|
| `js/hangul.js` | 오음 색, 모음 블록 모양, 자모 이름(읽기용), 글자 조합(유니코드 공식), 단어 사전 |
| `js/engine.js` | 화면과 무관한 규칙 엔진 + BFS 솔버 (브라우저 힌트·Node 검증 공용) |
| `js/levels.js` | 레벨 데이터 (6×5 문자 맵 + 블록/주머니 + 그림 단어) |
| `js/game.js` | Canvas 렌더링, 드래그 입력, 음성, 힌트/되돌리기, 애니메이션, 저장 |
| `tools/solve.js` | 레벨 솔버 |
