# 농기계 임대사업소

ENTJ 신규 주무관의 농기계 임대사업소 일주일 생존기. Godot 4로 만든 2D 경영 시뮬레이션입니다.

## 실행 방법

1. [Godot 4.3 이상](https://godotengine.org/download)(기본 버전, .NET 아님)을 설치합니다.
2. Godot 프로젝트 매니저에서 **가져오기(Import)** → 이 `nonggi` 폴더의 `project.godot`을 선택합니다.
3. 프로젝트를 열고 오른쪽 위 ▶ (또는 F5)를 누릅니다.

처음 열 때 폰트를 불러오느라 몇 초 걸릴 수 있습니다.

## 게임 방법

월요일부터 금요일까지 하루 09:00~18:00 일합니다. 1배속에서 현실 1초는 게임 시간 2분입니다.

| 화면 | 할 일 |
|---|---|
| **농기계 현황** (왼쪽) | 고장 난 장비 수리, 상태가 나쁜 장비 정기 정비 |
| **창구** 탭 | 예약한 농민에게 출고하기(바로 / 점검 후), 반납 받기(간단히 / 꼼꼼히) |
| **예약** 탭 | 들어온 예약 요청에 장비를 배정하거나 거절하기 |
| **전화·출장** 탭 | 고장 전화 → **출장 올리기** → **출발** → 현장 수리 → 복귀 → **출장 종료** |

- **출장비**: 출발부터 [출장 종료]를 누를 때까지 2시간 이상이면 1만 원, 2시간 미만이면 무급입니다.
  복귀하고 종료를 늦게 누르면 시간이 늘어나지만, 팀장에게 걸리면 출장비가 없어집니다.
- **점검을 건너뛰면** 빠르지만, 숨은 결함이 나중에 현장 고장으로 터집니다.
- **팀장(오 팀장)**: 매일 아침 회의와 내 행동에 따라 말을 걸어옵니다.
  - `직설`: ENTJ답게 할 말은 합니다. 스트레스는 줄지만 팀장 관계가 나빠집니다.
  - `수긍`: 일단 숙입니다. 관계는 좋아지지만 스트레스가 쌓입니다.
  - `절충`: 대안을 냅니다.
- **개선안 올리기**: 하루 한 번 쓸 수 있는 ENTJ의 본능입니다.

**게임 오버**: 팀장 관계 0(인사 발령), 스트레스 100(병가), 민원 만족 0(감사 착수).
5일을 버티면 수치에 따라 다른 주간 평가 엔딩이 나옵니다.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `scripts/data.gd` | 숫자와 대사: 장비 종류, 마을 거리, 출장비 규정, 팀장 대사. **난이도 조절은 여기서** |
| `scripts/game_state.gd` | 게임 규칙: 시간 흐름, 예약, 출고·반납, 수리, 출장, 엔딩 조건 |
| `scripts/main.gd` | 화면: 모든 UI를 코드로 만듭니다 |
| `scenes/main.tscn` | 시작 장면 (main.gd를 붙인 빈 노드) |
| `fonts/` | Pretendard 폰트 (SIL Open Font License) |
