# 농기계 임대사업소

ENTJ 신규 주무관이 농기계 임대사업소를 직접 걸어 다니며 일주일을 버티는 게임입니다.
포켓몬처럼 위에서 내려다보는 지도를 한 칸씩 걸어 다닙니다. Godot 4로 만들었습니다.

## 실행 방법

1. [Godot 4.3 이상](https://godotengine.org/download)(기본 버전, .NET 아님)을 설치합니다.
2. Godot 프로젝트 매니저에서 **가져오기(Import)** → 이 `nonggi` 폴더의 `project.godot`을 선택합니다.
3. 프로젝트를 열고 오른쪽 위 ▶ (또는 F5)를 누릅니다.

## 조작

| 키 | 동작 |
|---|---|
| 방향키 / WASD | 걷기 |
| Space / Enter / Z | 바라보는 것과 상호작용, 대화 넘기기 |
| Esc | 메뉴 닫기 |
| Tab | 업무 일지 |

## 사업소 지도

```
 [사무실]                         [장비 창고]
  서류함  팀장                     트랙터 관리기 …
  컴퓨터 내자리  전화                (장비마다 자리가 있다)
  ===== 창구 =====
  손님 줄                           
     │문                              │문
 ─────────── 마당 (반납 자리 / 출고 대기) ───────────
  안내판
 [주차장] 트럭
```

## 업무 흐름

- **대여**: 창구에서 손님 접수 → 창고로 걸어가 그 장비 앞에서 출고 (바로 / 점검 후)
- **반납**: 마당에 온 손님(또는 장비)에게 가서 확인 (간단히 / 꼼꼼히)
- **예약**: 사무실 컴퓨터에서 요청에 장비 배정
- **고장 전화**: 전화벨이 울리면 전화기로 달려가 받기 → 컴퓨터에서 **출장 올리기**
  → 주차장 **트럭**에서 출발 → 마을에서 고장 난 기계 수리 → 트럭으로 복귀
  → 사무실 컴퓨터에서 **출장 종료**
- **출장비**: 출발부터 [출장 종료]까지 2시간 이상이면 1만 원, 미만이면 무급.
  복귀하고 종료를 늦게 누르면 시간이 늘지만, 팀장에게 걸리면 출장비가 없어집니다.
- **수리·정비**: 창고의 고장 장비(빨간 !) 앞에서 수리
- **팀장**: 매일 아침 회의. 머리 위에 `!`가 뜨면 찾아가야 합니다 (30분 넘게 안 가면 관계 감소).
  `직설`(ENTJ답게) / `수긍` / `절충` 중에서 고릅니다. 하루 한 번 개선안도 올릴 수 있습니다.
- **내 자리**: 커피 한 잔으로 스트레스를 줄입니다 (하루 3번).

걸어 다닐 때는 현실 1초 = 게임 1분입니다. 수리나 트럭 이동 중에는 시간이 빨리 갑니다.
멀리 있는 일을 하러 가는 동안 다른 곳의 손님은 계속 기다립니다. **동선이 곧 실력입니다.**

**게임 오버**: 팀장 관계 0(인사 발령), 스트레스 100(병가), 민원 만족 0(감사 착수).
금요일까지 버티면 수치에 따라 다른 주간 평가 엔딩이 나옵니다.

## 파일 구조

| 파일 | 내용 |
|---|---|
| `scripts/data.gd` | 숫자, 대사, **지도**(글자로 그린 칸), 사람·장비 자리. 난이도와 지도는 여기서 |
| `scripts/game_state.gd` | 게임 규칙: 시간, 예약, 출고·반납, 수리, 전화, 출장, 엔딩 |
| `scripts/world.gd` | 걸어 다니는 지도: 이동, 충돌, 바라보는 대상, 도형으로 그리기 |
| `scripts/main.gd` | 대화창, 메뉴, 화면 위 정보(HUD), 날짜 넘기기 |
| `scenes/main.tscn` | 시작 장면 |
| `fonts/` | Pretendard 폰트 (SIL Open Font License) |

그림 파일 없이 도형으로 그립니다. 나중에 그림(스프라이트)으로 바꾸려면 `world.gd`의 `_person`, `_machine`, `_draw_tile`만 고치면 됩니다.
