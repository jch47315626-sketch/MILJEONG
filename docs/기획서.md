# 《자모냥》 기획서 (가칭)

> 한글 자음·모음으로 만드는 슬라이딩 블록 퍼즐
> 레퍼런스: 고양이 슬라이딩 수집 퍼즐 (색깔 블록을 밀어 같은 색 고양이를 모으는 방식)

---

## 1. 한 줄 컨셉

**모음 모양 블록을 밀어서, 같은 계열 자음을 태워 글자를 완성하는 퍼즐.**
블록 모양 자체가 모음(ㅣ, ㅡ, ㅏ, ㅗ…)이고, 자음 타일이 고양이 자리를 대신한다.

## 2. 레퍼런스 분석 → 한글 매핑

| 원작 요소 | 원작에서의 역할 | 한글 버전 |
|---|---|---|
| 색깔 블록 (긴 막대, L자, 사각형) | 드래그로 슬라이딩, 숫자만큼 같은 색 고양이 수집 | **모음 블록** — 모양이 모음 글꼴 그대로 (ㅣ=세로 1×3, ㅡ=가로 3×1, ㅏ·ㅓ·ㅗ·ㅜ=L/T형) |
| 블록 위 숫자 | 모아야 할 고양이 수 | 완성해야 할 **글자 수** |
| 고양이 (색별) | 수집 대상 | **자음 타일** (오음 계열별 색) |
| 고양이 색 일치 규칙 | 같은 색만 탐 | 블록 색 = 받을 수 있는 **자음 계열** |
| 가장자리 상자 + 숫자 | 대기열에서 고양이 계속 공급 | **자음 주머니** — 다음 자음 3개 미리보기 후 공급 |
| 생선뼈 블록 | 특수 블록 / 장애물 | **옛한글 블록 (ㆆ·ㅿ·ㆁ)** 또는 **먹물 얼룩** |
| 타이머 | 시간 제한 | 동일 (모드별 조정) |
| 하단 아이템 4종 | 얼리기·풍선·츄르·로켓 | 붓·지우개·도장·한지 (아래 7장) |

## 3. 색 규칙 — 훈민정음 오음(五音)

색을 그냥 임의로 정하지 않고 **발음 위치**로 묶는다. 플레이하다 보면 자연스럽게 자음 체계를 익히게 되는 게 포인트.

| 색 | 계열 | 자음 |
|---|---|---|
| 🟦 파랑 | 아음 (어금닛소리) | ㄱ ㅋ ㄲ |
| 🟥 빨강 | 설음 (혓소리) | ㄴ ㄷ ㅌ ㄸ ㄹ |
| 🟨 노랑 | 순음 (입술소리) | ㅁ ㅂ ㅍ ㅃ |
| ⬜ 흰색 | 치음 (잇소리) | ㅅ ㅈ ㅊ ㅆ ㅉ |
| 🟪 보라 | 후음 (목구멍소리) | ㅇ ㅎ |

> 초반 레벨은 색만 보고 맞춰도 클리어 가능 → 후반에는 색 힌트를 줄이는 "흑백 모드"로 실력 요구.

## 4. 코어 규칙

1. 보드는 격자(6×9 기본). 칸마다 자음 타일, 빈칸, 모음 블록, 장애물이 있다.
2. **모음 블록은 자기 방향으로만 슬라이딩**한다.
   - 세로형 모음(ㅣ ㅏ ㅓ ㅑ ㅕ) → 상하 이동
   - 가로형 모음(ㅡ ㅗ ㅜ ㅛ ㅠ) → 좌우 이동
   - 복합 모음(ㅘ ㅝ ㅢ 등) → 고정 블록, 자음이 와야 함
3. 블록이 같은 색 자음 타일과 **맞닿으면** 자음이 블록에 흡수되고, 그 자리에 글자가 찍힌다.
   - 예: 파랑 ㅏ 블록 + ㄱ → **가** 완성, 숫자 3 → 2
4. 숫자가 0이 되면 블록이 완성된 글자들을 띄우며 사라지고 공간이 열린다.
5. 자음이 빠진 자리로 위쪽 타일이 떨어지거나, 자음 주머니에서 새 자음이 들어온다.
6. **모든 블록을 비우면 클리어.** 시간 초과 또는 이동 불가 시 실패.

### 위치 규칙 (난이도 장치)
실제 한글 조합처럼 **자음이 붙는 방향**을 제한할 수 있다.
- 세로 모음(ㅏ ㅓ ㅣ): 자음은 **왼쪽**에서만 흡수
- 가로 모음(ㅗ ㅜ ㅡ): 자음은 **위쪽**에서만 흡수

→ 초반엔 끄고(아무 방향 OK), 월드 2부터 켜서 "한글 조합 원리 = 퍼즐 규칙"이 되게 만든다.

## 5. 보너스 — 단어 만들기

블록 하나가 완성한 글자들이 순서대로 **실제 단어**가 되면 보너스.
- 파랑 ㅏ 블록이 `가`, `카`를 만들고 빨강 ㅏ 블록이 `다`를 만듦 → 따로 판정
- 같은 블록 안에서 `나·라` 처럼 이어지면 2음절 단어 체크 → 사전 DB 매칭 시 코인 ×2
- 레벨별 **숨은 단어** 1개: 맞추면 별 3개 조건 달성

## 6. 받침 모드 (월드 3~)

- 글자가 완성된 블록 아래쪽에 **받침 슬롯**이 생긴다.
- 받침 슬롯은 같은 색 제한 없이 아무 자음이나 받지만, 받침이 들어간 글자가 단어가 되면 큰 보너스.
- 겹받침(ㄳ ㄺ ㄻ…)은 자음 2개를 연속으로 붙여야 하는 고급 기믹.

## 7. 기믹 & 장애물

| 이름 | 효과 |
|---|---|
| **쌍자음 타일** (ㄲ ㄸ ㅃ ㅆ ㅉ) | 한 번에 2칸 카운트, 대신 블록 숫자 2 이상일 때만 흡수 |
| **옛한글 블록** (ㆆ ㅿ ㆁ) | 원작 생선뼈 역할. 움직이지 않는 장애물, 인접 블록 3개 완성 시 사라짐 |
| **먹물 얼룩** | 칸을 가림. 인접 칸에서 글자 완성되면 걷힘 |
| **자음 주머니** | 가장자리 상자. 숫자만큼 자음 공급, 다음 3개 미리보기 |
| **회전 모음** | ㅏ↔ㅓ, ㅗ↔ㅜ 탭으로 뒤집기 (방향 규칙 켜진 레벨용) |
| **얼음 자음** | 두 번 닿아야 흡수 |

## 8. 아이템 (하단 4종)

| 아이콘 | 이름 | 효과 |
|---|---|---|
| 🖌️ | 붓 | 자음 하나의 색(계열)을 원하는 색으로 바꿈 |
| 🧽 | 지우개 | 장애물/자음 하나 제거 |
| 🔴 | 도장 | 블록 하나를 즉시 완성 처리 |
| 📜 | 한지 | 타이머 30초 정지 |

## 9. 레벨 구성

| 월드 | 테마 | 새 요소 | 레벨 수 |
|---|---|---|---|
| 1. 서당 | 기본 모음 ㅏ ㅣ ㅡ | 색 맞추기, 슬라이딩 | 1~20 |
| 2. 장터 | ㅓ ㅗ ㅜ + 방향 규칙 | 위치 규칙, 자음 주머니 | 21~45 |
| 3. 궁궐 | ㅑ ㅕ ㅛ ㅠ + 받침 | 받침 슬롯, 쌍자음 | 46~75 |
| 4. 집현전 | 복합 모음, 옛한글 | 옛한글 장애물, 먹물 | 76~110 |
| 5. 흑백 서고 | 전 요소 | 색 힌트 제거 | 111~ |

**레벨 설계 원칙**
- 블록 수 3~8개, 완성 글자 총합 10~30
- 첫 수가 뻔하지 않도록 "막힌 블록 → 다른 블록 먼저" 구조 1개 이상
- 각 월드 마지막 레벨은 숨은 단어가 테마 단어(서당→`글`, 궁궐→`왕` 등)

## 10. 점수 & 보상

- 기본: 글자 1개 = 10점
- 단어 보너스: 2음절 ×2, 3음절 ×3
- 남은 시간 1초 = 5점
- 별 3개 조건: ① 클리어 ② 시간 절반 이상 남김 ③ 숨은 단어 완성
- 코인 → 아이템 구매

## 11. 아트 방향

- 원작 고양이 자리에 **자음 캐릭터**: 자음 글꼴을 몸통으로 한 동글동글한 캐릭터 (ㅇ은 동그란 얼굴, ㅁ은 네모 상자 몸 등)
- 모음 블록은 **한지·나무 질감**의 굵은 붓글씨 모양
- 글자 완성 시 붓 터치 이펙트 + 도장 "쾅" 사운드
- 배경: 서당 → 장터 → 궁궐로 바뀌는 한옥 톤

## 12. 기술 메모 (웹 기준)

- 엔진: HTML5 Canvas 또는 Phaser 3
- 글자 조합: 유니코드 공식 `0xAC00 + (초성×21 + 중성)×28 + 종성`
- 단어 판정: 국립국어원 기초어휘 목록을 압축 JSON으로 번들
- 레벨 데이터: JSON (격자, 블록 좌표/모양/색/숫자, 주머니 시퀀스)
- 풀이 검증: BFS 솔버로 레벨마다 해답 존재 + 최소 수 계산 → 난이도 자동 산정

```json
  "size": [6, 9],

```

## 14. 열린 질문

- 블록이 자음을 "맞닿으면" 흡수 vs "지나가면" 흡수 — 원작 동작 확인 후 결정
